📺 Tunarr Bumper Studio

Connections

No Plex connection needed — bumpers are written straight into a folder registered in Tunarr as a Local Media Source, so only Tunarr itself needs to be reachable.

The CPU limit hard-caps ffmpeg's actual usage (e.g. 50 = half a core) regardless of how many threads it spawns internally, trading render speed for a lighter system footprint. 0 leaves it unlimited. Applies to every channel's renders.

Channels

    Drag the labels on the canvas to position them. Canvas preview is a lightweight approximation — click "Render Real Preview" to see the actual ffmpeg output.

    Tunarr mapping

    The local media source should point at the same folder this app writes bumpers into — see the README for one-time setup.

    Backgrounds (picked at random each generation)

      Add as many as you like — images, gifs, or video clips can be mixed together. One is chosen at random on every regeneration.

      Background music (picked at random, optional)

        If narration is also on, music ducks quietly underneath it. With no narration, music plays at normal volume and fades out at the end of the clip.

        Font
        Rectangles / bars

          e.g. a solid bar across the bottom 20% of the screen for text to sit on. Positions/sizes are in % of the frame.

          Text line 1
          Text line 2

          Text placeholders: {show} and {time} (the show picked above and its start time), or name one directly: {current}, {next}, {later} (the show after next), {current_time}, {next_time}, {later_time}. Example: UP NEXT: {next} AT {next_time}. A line that names a show the guide doesn't have yet is left off.

          Timing & voice

          Download a voice's .onnx + .onnx.json pair from the Piper voices repo and place both in the uploads volume, then point this at the .onnx path. Leave narration off if you'd rather skip TTS.
